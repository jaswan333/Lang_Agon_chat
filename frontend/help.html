How to use VoiceAI

Everything you need to get started with the multilingual voice chatbot.

1

Choose a Language

Select English, Tamil, or Hindi from the sidebar to open that language's chat page.

2

Allow Microphone

Click Allow when your browser asks for microphone permission.

3

Click Mic or Type

Press the mic button and speak — recording stops automatically when you go silent, or click the red stop button for instant control. On English, you can also type your question.

4

Hear the Response

AI replies in text and voice in your selected language. The waveform shows your mic is active.

Tech Stack
🎙️
Whisper STT
Groq's whisper-large-v3 converts your voice to text with forced language detection.
🤖
Groq LLaMA 3.3
Ultra-fast LLaMA 3.3 70B model generates intelligent responses via Groq API.
🔊
gTTS
Google Text-to-Speech converts AI responses to natural voice audio.
🐍
Flask Backend
Python Flask handles all API routes, audio processing, and serves the frontend.
Common Issues
❌ Microphone not working?
Go to browser Settings → Privacy → Microphone and allow this site.
❌ 500 Server Error?
Make sure Flask is running: cd backend && python app.py. Check your .env has a valid GROQ_API_KEY.
❌ No voice output?
gTTS needs internet. Check your network and ensure system volume is not muted.
❌ Recording stops too fast?
Speak louder or closer to the mic. The silence threshold is set to detect low volume as silence.
❌ Wrong language transcribed?
Each chat page forces its own language. Make sure you opened the correct language page from the sidebar.
🎨 Emotion tags not showing?
Emotion detection works on text patterns. Try using more expressive language like "This is frustrating!" or "Wow, that's amazing!" to trigger emotion detection.
