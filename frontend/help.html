How to use VoiceAI

Everything you need to get started with the multilingual voice chatbot.

1

Choose a Language

Select English, Tamil, or Hindi from the sidebar on the left to open that language's chat page.

2

Allow Microphone

When prompted by your browser, click Allow to grant microphone access. This is required for voice input.

3

Click the Mic Button

Press the blue microphone button. It will turn red and start recording for 4 seconds. Speak clearly during this time.

4

Wait for AI Response

After recording, the AI processes your speech and replies in text and voice automatically. The response plays in your selected language.

Tech Stack
🎙️
Whisper STT
OpenAI Whisper converts your voice to text accurately across all 3 languages.
🤖
Groq LLaMA 3.3
Ultra-fast LLaMA 3.3 70B model via Groq API generates intelligent responses.
🔊
gTTS
Google Text-to-Speech converts AI responses back to natural voice audio.
🐍
Flask Backend
Python Flask handles all API routes, audio processing, and serves the frontend.
Common Issues
❌ Microphone not working?
Check browser permissions. Go to browser Settings → Privacy → Microphone and allow this site.
❌ 500 Server Error?
Make sure the Flask server is running: cd backend && python app.py. Also verify your .env has a valid GROQ_API_KEY.
❌ No voice output?
gTTS requires an internet connection. Check your network. Also ensure your system volume is not muted.
❌ Whisper not transcribing?
Ensure ffmpeg is installed and added to your system PATH. Run ffmpeg -version to verify.
